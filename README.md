```bash
pip install -r requirements.txt
python -m mcn_studio.demo
```

## 核心功能

- **多 Agent 协作**：24 名数字员工，涵盖编剧、导演、运营、合规等角色
- **配额闸门**：免费用户每日 3 条额度，超限自动触发 Pro 升级 CTA
- **合规审查**：平台敏感词检测 + 价值导向过滤
- **批量生成**：Pro 用户支持 10 集/次批量产出
- **多平台分发**：抖音/红果/快手一键同步
