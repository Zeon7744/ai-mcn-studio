# ai-mcn-studio · AI 短剧/MCN 创作引擎

AI 短剧/MCN 全链路创作引擎：剧本生成 → 角色设定 → 分镜 → 视频提示词 → 合规审查 → 多平台分发。

## 快速上手

```bash
pip install -r requirements.txt
python main.py --generate "霸道总裁短剧" --platform douyin
```
