# AI MCN Studio v3.0 — 人工智能MCN工作室

一个基于多Agent协作的AI驱动MCN工作室系统，覆盖短视频、直播、品牌商单、IP孵化、
热点借势、私域运营、危机公关、版权管理、内容审核、数据异常、海外出海全业务线。

## 分级管理模型（集中+分布双模）

- **集中管理（CEO直接介入）**：重大危机（crisis_management工作流）、合规红线事件、
  跨部门资源冲突、重大商务决策。
- **分布管理（总监自主）**：日常选题、常规商单、例程发布，由各总监在授权范围内决策。
- **升级机制**：专员24h内无法裁决 → 升级总监 → 总监无法裁决 → 升级CEO。

## 快速开始

```bash
# 运行完整演示（组织架构/知识库/工作流/案例全展示）
python demo.py

# 进入交互模式
python main.py

# 常用命令行参数
python main.py --org          # 打印分级组织架构图
python main.py --status       # 打印团队JSON状态
python main.py --workflows   # 列出12套工作流
```

交互模式扩展命令：
- `team` / `org` / `status` — 团队视图
- `create <name> <goal> <platform> [template]` — 创建项目（6种模板）
- `run <workflow> <project>` — 执行工作流（12套）
- `agent <姓名> <任务类型> <描述>` — 直接与任意数字员工对话
- `crisis <事件>` — 触发CEO级危机响应

## 工作流系统（12套，全业务无死角）

1. **短视频生产流程** (6步) — 选题→脚本→视觉→合规→发布策略→发布执行（星轨）
2. **直播带货流程** (10步) — 选品（甄宝）→报价谈判（鸿鹄）→主播规划（声优）→话术（笔灵）→直播策划（燃点）→视觉（绘影）→预热（数策）→合规（镜鉴）→直播执行（令仪）→复盘（鉴往）
3. **品牌商单流程** (8步) — 需求→创意→报价谈判（鸿鹄）→脚本→制作→审核→发布→结算
4. **IP孵化加速流程** (9步) — 赛道分析（墨言）→选题评估（文渊）→人设（知微）→视觉（绘影）→内容（笔灵）→冷启动（数策）→变现（利达）→合规（镜鉴）→启动（令仪）
5. **热点借势响应流程** (6步, SLA<4h) — 热点捕获（疾风）→立项→快速脚本/视觉→合规快审→加急发布
6. **私域运营增长流程** (6步) — 粉丝画像（慧眼）→触点设计（暖暖）→钩子→UGC→变现→监控
7. **危机公关流程** (7步, CEO集中管理) — 定级（令仪）→舆情监控→溯源→声明→合规→执行→复盘
8. **素材版权管理流程** (5步) — 登记（版权）→授权核验→原创度→发布确认→侵权响应
9. **内容三级审核流水线** (5步) — 自检（笔灵）→互审（墨言）→合规（守法）→视觉质检（帧刻）→终审（数策）
10. **数据异常响应流程** (6步) — 发现（慧眼）→根因（数策）→外部因素（瞭望）→止血→迭代→复盘（鉴往）
11. **海外平台出海流程** (5步) — 市场研究（博闻）→本地化（笔灵）→账号策略（数策）→海外合规→发布（星轨）
12. **账号矩阵运营流程** (6步) — 矩阵规划（数策）→人设视觉（知微）→多账号排期（星轨）→流量互导（慧眼）→矩阵合规（守法）→矩阵复盘（鉴往）
