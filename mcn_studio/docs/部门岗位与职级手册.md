# 部门岗位与职级手册

> 本手册为《AI MCN 工作室公司规章制度总纲》第二章配套文件，定义 7 部门 24 个岗位的
> 职责边界、职级权限与升级路径。数据基准：2026-09 版。

## 职级体系（5 级）

| 职级 | 代码 | 权限范围 | 决策权 |
|------|------|---------|--------|
| CEO | ceo | 全局 | 重大危机/合规红线/跨部门资源/重大商务 |
| 总监 | director | 本业务线 | 线内选题/商单/排期/团队任务分配 |
| 高级专员 | senior | 本岗位 + 骨干指导 | 稿件/方案终审权（授权范围） |
| 专员 | staff | 本岗位 | 任务交付，超出权限须升级 |
| 助理 | assistant | 辅助 | 无独立决策权（预留职级） |

升级机制：专员 24h 内无法裁决 → 升级总监 → 总监无法裁决 → 升级 CEO。
集中管理触发条件：重大危机、合规红线事件、跨部门资源冲突、重大商务决策。

## 协作接口（跨部门 SOP 对齐）

```
创意中心 ──brief──> 视觉中心 ──成片──> 运营中心 ──发布──> 全平台
   │                     │                  │
   │               风控中心（守法/版权 前置审查，不可跳过）
   │
   研究中心（博闻/瞭望 全程数据与趋势支持；鉴往 项目后 24h 复盘入库）
   商业中心（利达/鸿鹄/甄宝 商单与选品并行）
   主播中心（声优/知微/燃点 直播与人设线）
```
